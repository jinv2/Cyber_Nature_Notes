# 🌿 赛博自然笔记 (Cyber Nature Notes) - No.29

![Shensist Logo](assets/logo_ts.webp)

> **跨物种共情对话翻译器 | 官方联动版 V2.5**

这是一个基于 Web 技术构建的交互式赛博自然感应终端，旨在通过 AI 逻辑与自然灵魂（地衣、抹香鲸、蚯蚓）进行非考核倾向的创意对话。

## ✨ 核心特性

- **灵魂注入逻辑引擎**：基于关键词感应的即时进化对话逻辑。
- **山海灵脉视觉效果**：动态网格背景与高级毛玻璃感应界面。
- **官方矩阵联动**：一键访问神思官网 [shensist.top](https://shensist.top/)。
- **全端自适应**：完美兼容 PC 与移动端触控体验。
- **自主学习规范**：遵循 2026 教育部 AI 教学规范，强调创意而非分数。

## 🚀 快速开始

只需在浏览器中打开 `index.html` 即可开始你的自然感应之旅。

## 🛠️ 技术栈

- **Core**: HTML5, Vanilla JavaScript
- **Style**: Tailwind CSS, CSS Animations
- **Logic**: Shensist-Logic-Responsive Engine V7.2
